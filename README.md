# Sefa Beach — QR menu & revenue prototype (2026-11-13)

## Что внутри
- `index.html`: статический сайт, 123 позиции, локализация RU/TR/EN, быстрая навигация, категория/поиск, избранное, корзина с передачей списка официанту, предлагаемые дополнения, загрузка карточек по 12.
- `original-sefa-beach-demo.html`: архивный исходник от 07.11.2026 (не считать синхронизированным с live-сайтом без проверки).
- `menu-baseline.json`: исходные названия и цены, **все цены требуют подтверждения** владельцем.
- `revenue-dashboard-local.html`: локальный расчёт выручки, среднего чека и вклада на базе выгрузки реальных строк заказов. Не POS и не live-аналитика.
- `sales-lines-template.csv`: шаблон импорта чеков; пока без реальных продаж.
- `menu-cost-template.csv`: шаблон для ручной проверки себестоимости каждой позиции.

## Опубликовать как GitHub Pages
1. Создать пустой публичный репозиторий `safal207/sefa-beach` в GitHub, **если его ещё нет**.
2. Загрузить `index.html` в корень репозитория и при желании `README.md`, `menu-baseline.json`. **Не загружать реальные данные продаж**.
3. GitHub repo → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)` → Save.
4. Проверить сайт по адресу `https://safal207.github.io/sefa-beach/` (адрес начнёт работать **после успешной публикации**, сейчас не подтверждён).

## QA / acceptance gates
- [ ] Точный адрес, часы работы, телефон подтверждены (официальная страница и Яндекс расходятся по району/часам).
- [ ] 123 названия блюд и цены подтверждены рестораном; пять цен отсутствуют.
- [ ] Фотографии конкретных блюд и лицензии подтверждены; 14 шаблонов фото не эквивалентны 123 реальным фото.
- [ ] Корзина используется **только** для списка официанту, не как реальная система заказа/оплаты.
- [ ] TR, EN, RU: поиск, навигация, корзина, доп. позиции, тема и мобильная вёрстка.
- [ ] Для расчёта фактической маржи импортированы реальные чеки с ID, корректными суммами и себестоимостью.
- [ ] До согласования с владельцем оставлен `noindex,nofollow`.

## Формула финансового отчёта
`net_sales = qty * paid_unit_price - discount - refund`
`contribution = net_sales - qty * (unit_food_cost + unit_packaging_cost) - payment_fee`
`AOV = sum(net_sales) / count(distinct order_id)`

Вклад после переменных затрат **не равен чистой прибыли**; исключены аренда, зарплаты, налоги, коммунальные расходы и прочие общие затраты. Не создавайте фиктивные показатели.

GitHub-репозиторий и публикация GitHub Pages не создаются автоматически этим архивом. Фотографии из Unsplash являются иллюстративными. Публичный сайт демонстрационный, не официальный ресурс ресторана до получения согласия владельца.
